# Liberty Moving

Toronto moving website built with React, TypeScript, Vite, and Tailwind CSS.

## Contact

Liberty Moving calls and texts use **(647) 874-3551**. The other business numbers are not used by this website.

## Quote requests

The form requires a name, callback number, pickup and destination locations, and moving date. It prepares a text message addressed to Liberty Moving. Customers must open their text app and press Send; preparing the message does not submit a request. A phone call is the fallback for devices without text support. No quote price is calculated and no automated callback is promised.

## Development and validation

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

GitHub Actions runs type checking and the production build for pull requests and pushes to main.

Before launch, check call and text links on iPhone and Android, including recipient and message contents. Confirm actual service availability and business claims, and review the external image assets. Example projects are illustrative.
